# PK AI - Personal Voice Assistant

PK AI is a desktop AI assistant built using Python, CustomTkinter, Ollama and Speech Technologies.

## Features

* AI Chat using Ollama (Phi-3 Mini)
* Voice Response using pyttsx3
* Google Search Integration
* Modern GUI with CustomTkinter
* Keyboard Enter Support
* Offline AI Processing

## Technologies Used

* Python
* Ollama
* Phi-3 Mini
* CustomTkinter
* pyttsx3
* Vosk
* SpeechRecognition

## Installation

```bash
pip install -r requirements.txt
```

Run:

```bash
python gui.py
```
